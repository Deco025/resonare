# p1_rx 生产文件（接收板 RX）

由 `kicad-cli` 从 `p1_rx.kicad_pcb` 导出，坐标原点 = 板左上角（钻孔/贴片原点）。

## 下单参数

| 项 | 值 |
|---|---|
| 层数 | 4 层 |
| 板厚 | 1.6 mm，FR4 |
| 铜厚 | 外层 2 oz（70 µm），内层 1 oz（35 µm） |
| 叠层 | F.Cu / 0.2 PP / In1（GND_RX 整层）/ 0.97 芯板 / In2（VRECT 整层）/ 0.2 PP / B.Cu，**内层顺序不要调换** |
| 尺寸 | 75 × 60 mm |
| 表面处理 | 无铅喷锡（HASL lead-free） |
| 阻焊 / 丝印 | 绿油 / 白字 |
| 过孔 | 盖油（丝印有少量印在过孔上） |
| 最小线宽 / 间距 | 0.2 / 0.2 mm |
| 过孔（外径/孔径） | 0.5/0.3（18 个）、0.6/0.3（85 个）、0.8/0.4（104 个）；最小焊环 0.1 mm |
| 焊盘孔 | PTH 1.0 / 1.3 / 2.7 mm，NPTH 3.2 mm（4 个安装孔） |
| 槽孔 | 2 个 0.6 × 1.7 mm 金属化槽孔（钻孔文件里按槽孔输出） |

外层 2 oz 下的 0.2 / 0.2 mm 线宽线距、0.1 mm 焊环，下单前请对照所选板厂的工艺能力确认。

## 文件

- `p1_rx-gerber.zip`：上传用，含 11 层 Gerber（X2）、PTH/NPTH 分开的 Excellon 钻孔、`.gbrjob`。
- `gerber/`：同上的散文件，另有钻孔分布图 PDF。
- `p1_rx-bom.csv`：按 值 + 耐压 + 封装 合并。线圈模型（L302/L601）不在板上、安装孔 H1–H4 不贴装。
- `p1_rx-pos.csv`：贴片坐标（mm，y 向上为正的 KiCad 惯例，原点在板左上角，全部为顶面）。若用嘉立创 SMT，需要按其模板改列名并补 LCSC 料号。
- `p1_rx-assembly.pdf`：装配图（F.Fab 层，含丝印上放不下而隐藏的 29 个小阻容位号）。
- `p1_rx-drc.rpt`：DRC 报告：0 错误、0 未连接；剩下的都是已接受的丝印项（驱动器 1 脚三角压自举电容焊盘 0.05–0.14 mm、接线端子外框到板边），板厂会自动裁掉焊盘上和板外的丝印。
